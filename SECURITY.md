# Security policy

## Supported versions

Only the latest release on the `main` branch receives fixes.

## Reporting a vulnerability

Please do not describe a security problem in a public issue. Open an issue titled
**"Security contact"** with no details, and a private channel will be arranged to receive them.
Include then the version (`qi version`), the input or command that shows the problem, and what
you expected.

What the tool protects against, and what it does not, is described in
[docs/security.md](docs/security.md).
