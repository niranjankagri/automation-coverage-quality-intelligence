# Security policy

## Supported versions

Only the latest release on the `main` branch receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability
reporting: **Security → Report a vulnerability** on this repository's page. Include the version
(`qi version`), the input or command that shows the problem, and what you expected.

What the tool protects against, and what it does not, is described in
[docs/security.md](docs/security.md).
