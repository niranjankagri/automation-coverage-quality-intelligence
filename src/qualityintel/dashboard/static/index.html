    Dashboard guide and glossary

    Start with the release readiness decision and its observed reasons. Follow linked evidence to the relevant test, requirement, run or pipeline, then use the breadcrumbs to return to the results.

    Coverage
    Requirements linked to at least one test case, divided by requirements in scope. Linked manual or planned tests count.
    Automation coverage
    Linked test cases marked automated, divided by all linked test cases. Unlinked cases are reported separately.
    Pass rate
    Passed results divided by passed, failed and error results in the latest snapshot. Skips are excluded; it does not measure requirement coverage.
    Flaky candidate
    A pattern of mixed outcomes that the history rules suspect may be flaky. It is a candidate for investigation, not a proven cause.
    Stale evidence
    The latest execution of a requirement's linked tests is older than the configured dashboard threshold.
    Readiness
    The existing release gate result plus documented warnings for missing evidence, flaky candidates, incomplete collections or stale dashboard data.
